# まなびアプリ（フェーズ1: ひらがなMVP）

小学生向けの書き取り学習アプリ。Safari PWA（ホーム画面に追加）で、
本物のアプリのようにフルスクリーン・オフラインで動作します。
サーバーやビルド不要、静的ファイルだけで動く構成です。

## 今できること（フェーズ1）

- ひらがな46文字の**練習モード**（書き順番号つきガイド、お手本アニメーション）
- **テストモード**（ガイドなしで実力確認）
- 書いた文字の自動採点（形の正しさ＋書き順・向きの正しさ）
- 間違えた画を具体的に指摘するフィードバック
- できたときの演出（音・紙吹雪・段階的な褒め言葉）
- 進捗の保存（習熟度に応じてタイルの色が変化）
- 苦手な文字を優先的に出す「きょうのふくしゅう」
- 学習の連続日数・シール数の記録（マイページ）
- 進捗データのバックアップ書き出し／読み込み（iOSのストレージ消去対策）
- 文字の読み上げ（🔊ボタン、Web Speech API）

カタカナ・漢字・英語、中学生以降への拡張は次フェーズ以降で追加していきます
（[js/data/hiragana.js](js/data/hiragana.js) と同じ形式でデータを追加するだけで拡張できる設計です）。

## iPadで使う（配布・インストール手順）

このアプリはビルド不要ですが、`file://` では動きません（ES Modulesの制約のため）。
どこかにホスティングしてURL経由で開く必要があります。個人利用なら **GitHub Pages** が無料で簡単です。

1. このフォルダの中身をGitHubリポジトリにアップロードする
2. リポジトリの Settings → Pages で公開する（ブランチ・ルートを指定するだけ）
3. 発行されたURL（例: `https://ユーザー名.github.io/リポジトリ名/`）をiPadのSafariで開く
4. 共有ボタン → 「ホーム画面に追加」
5. ホーム画面のアイコンから起動すると、フルスクリーンのアプリとして動きます

GitHubを使いたくない場合は、Netlify Drop（フォルダをドラッグ＆ドロップするだけ）などでも代用できます。

### アプリを更新したとき

[service-worker.js](service-worker.js) の `CACHE_VERSION` の数字を上げてから再公開してください。
上げないと、端末に古いキャッシュが残って更新が反映されないことがあります。

macOSやXcodeがない環境で開発しているため、実機での見た目や操作感は

- 「ホーム画面に追加」後のアイコン・フルスクリーン表示
- 機内モードにしてオフラインでも開けるか

## 採点の仕組み（技術メモ）

漢字・かな1文字ずつの正確な筆順データを手作業で全部作るのは大変なため、
判定は次の2つを組み合わせています。

1. **形の正しさ**: iPadに内蔵されている実際の日本語フォントで文字を描画し、
   それと利用者が描いた線を画像として比較（重なり具合をスコア化）。
   これにより、座標データが多少ラフでも「ちゃんと書けているか」は精度よく判定できます。
2. **書き順・向きの正しさ**: [js/data/hiragana.js](js/data/hiragana.js) に定義した
   各画の開始点・終了点のおおまかな座標と、利用者が実際に描いた画の始点・終点を比較。

このため `hiragana.js` の座標は「だいたい合っていればOK」で、
神経質にピクセル単位で合わせる必要はありません。今回はこの方針で46文字分を作成済みです。
実際に子どもが使ってみて厳しすぎる／甘すぎると感じたら、
[js/judge.js](js/judge.js) 内の `TOLERANCE`（許容範囲）や得点の重み付けを調整してください。

## 動作確認用の裏機能

URLの末尾に `#list` / `#mypage` / `#write=hiragana_a:practice` などを付けると、
そのままその画面を開けます（開発・デバッグ用。通常の利用では使いません）。

## フォルダ構成

```
manabi-app/
  index.html          エントリーポイント
  manifest.json        PWA設定
  service-worker.js    オフラインキャッシュ
  css/style.css
  js/
    app.js             画面遷移・イベント配線
    ui.js              画面HTMLテンプレート
    canvas.js           書き込みキャンバス(ポインタ入力・お手本アニメーション)
    judge.js             採点エンジン
    storage.js           進捗保存・バックアップ
    data/hiragana.js     文字データ(将来カタカナ・漢字・英語もここに追加)
  icons/                アプリアイコン(tools/make_icons.pyで生成)
  tools/make_icons.py   アイコン生成スクリプト
```
