# まなびアプリ（フェーズ2: ひらがな・カタカナ）

小学生向けの書き取り学習アプリ。Safari PWA（ホーム画面に追加）で、
本物のアプリのようにフルスクリーン・オフラインで動作します。
サーバーやビルド不要、静的ファイルだけで動く構成です。

## 今できること

- **ひらがな46文字・カタカナ46文字**の練習モード（書き順番号つきガイド、お手本アニメーション）
- **テストモード**（ガイドなしで実力確認）
- 書いた文字の自動採点（形の正しさ＋書き順・向きの正しさ）
- 間違えた画を具体的に指摘するフィードバック
- できたときの演出（音・紙吹雪・段階的な褒め言葉）
- 進捗の保存（習熟度に応じてタイルの色が変化。色の意味は一覧画面に凡例を表示）
- 苦手な文字（直近3回の平均が70点未満）を優先的に出す「きょうのふくしゅう」
- きょうのもくひょう（1日5文字。ホーム画面に「あと何文字か」を丸で表示）
- ごほうびシールずかん（全72種／6アルバム。がんばりポイント6点で1枚もらえ、レア・スーパーレアもある）
- 学習の連続日数などの記録（マイページの「おうちの方へ」欄）
- 進捗データのバックアップ書き出し／読み込み（iOSのストレージ消去対策）
- 文字の読み上げ（🔊ボタン、Web Speech API）

漢字・英語、中学生以降への拡張は次フェーズ以降で追加していきます。
文字データは `python tools/fetch_kanjivg.py` で生成し、[js/subjects.js](js/subjects.js) に1行足すだけで教科を追加できます。
シールも [js/data/stickers.js](js/data/stickers.js) にアルバムを足すだけで増やせます。

## iPadで使う（配布・インストール手順）

このアプリはビルド不要ですが、`file://` では動きません（ES Modulesの制約のため）。
どこかにホスティングしてURL経由で開く必要があります。個人利用なら **GitHub Pages** が無料で簡単です。

1. このフォルダの中身をGitHubリポジトリにアップロードする
2. リポジトリの Settings → Pages で公開する（ブランチ・ルートを指定するだけ）
3. 発行されたURL（例: `https://ユーザー名.github.io/リポジトリ名/`）をiPadのSafariで開く
4. 共有ボタン → 「ホーム画面に追加」
5. ホーム画面のアイコンから起動すると、フルスクリーンのアプリとして動きます

GitHubを使いたくない場合は、Netlify Drop（フォルダをドラッグ＆ドロップするだけ）などでも代用できます。

### アプリを更新したとき

[service-worker.js](service-worker.js) の `CACHE_VERSION` の数字を上げてから再公開してください。
上げないと、端末に古いキャッシュが残って更新が反映されないことがあります。

## 文字データについて（KanjiVG）

書き順の線データは、オープンソースの漢字・かな筆順データベース
**[KanjiVG](https://kanjivg.tagaini.net/)**（Copyright © 2009-2011 Ulrich Apel、
[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) ライセンス）を使用しています。

1画ずつ分離された正式な筆順ベクターデータのため、書き順・画数が教科書どおりです。
カタカナ・漢字も同じ方法で追加できます（[tools/fetch_kanjivg.py](tools/fetch_kanjivg.py) を実行するだけ）。

## 採点の仕組み（技術メモ）

**画面に薄く表示されるお手本・なぞりアニメーション・採点の基準が、
すべて同じ線データ（上記のKanjiVGのパス）** になっています。
そのため「お手本どおりになぞったのに減点される」ということが起きません。

1. **形の正しさ**: お手本の線と、書いた線を画像として重ね合わせて一致度をスコア化。
   このとき、書いた文字全体の位置・大きさをお手本に合わせて補正してから比較するので、
   多少小さく書いたり位置がずれたりしても、形が合っていれば正しく評価されます。
2. **書き順・向きの正しさ**: 各画の書きはじめ・書きおわりの位置を、お手本の各画と比較。

厳しすぎる／甘すぎると感じたら、[js/judge.js](js/judge.js) 冒頭の
`TOLERANCE`（書きはじめ位置の許容範囲）や `DILATE_PASSES`（形のゆるさ）、
得点の重み付けを調整してください。

## 動作確認用の裏機能

URLの末尾に付けると、その画面・状態を直接開けます（開発・デバッグ用）。

| ハッシュ | 内容 |
|---|---|
| `#list` / `#list=katakana` / `#mypage` | その画面を開く |
| `#write=hiragana_a:practice` | 「あ」の練習画面を開く（`:test`でテストモード） |
| `#preview=hiragana_a:1:0.5` | お手本を「1画目まで完了＋2画目を50%」の状態で表示 |
| `#test=hiragana_a:good` | お手本どおりに書いた場合の採点結果（`bad`=書き順逆、`shift`=小さく右下寄り） |

## フォルダ構成

```
manabi-app/
  index.html          エントリーポイント
  manifest.json        PWA設定
  service-worker.js    オフラインキャッシュ
  css/style.css
  js/
    app.js               画面遷移・イベント配線
    ui.js                画面HTMLテンプレート
    subjects.js          教科の定義(ひらがな・カタカナ…。追加はここに1行)
    canvas.js            書き込みキャンバス(ポインタ入力・お手本アニメーション)
    strokePaths.js       書き順パスの共通ヘルパー
    judge.js             採点エンジン
    storage.js           進捗・シール・バックアップ
    data/
      kvg.js             書き順パスの座標系(109x109)
      hiragana.js        ひらがなの文字データ(自動生成)
      katakana.js        カタカナの文字データ(自動生成)
      stickers.js        ごほうびシールのアルバム定義
  icons/                 アプリアイコン
  tools/
    fetch_kanjivg.py     文字データの生成(KanjiVGから取得)
    make_icons.py        アイコン生成
```
